# Resource inventory

Every visual and outside resource the learning environment needs, by subject.
Status: **idea** → **built** → **checked** (accuracy reviewed) → **live**.

## Visual style

Modeled on two examples:

- **π** – a circle with diameter 1 rolls along a number line; after one turn
  it stops at 3.14159….
- **Sine waves make shapes** – sine waves are added one at a time and build a
  square wave; spinning circles stacked end to end trace a drawing.

Rules that follow from them:

1. **One idea, one motion.** Each visual shows a single thing happening.
2. **Silent.** No voice-over; the student supplies the explanation. That is
   what gets graded.
3. **Simple shapes on a clean board.** Quantitative ideas sit on a Cartesian
   grid; a few short handwritten-style notes appear as the motion plays.
4. **Short and looping.** About 5–15 seconds, so a student can rewatch while
   explaining.
5. **Reusable in the movie.** A subject's movie is its visuals played in track
   order, with narration added.

## Visual patterns

Most visuals reuse one of these motions, so each new one is mostly a fill-in.

| Pattern | What moves | Example |
|---|---|---|
| Unroll | A shape unrolls or rearranges into another | π: circle rolls out to 3.14… |
| Trace | A moving point leaves a curve behind it | Point on a circle traces a sine wave |
| Build-up | Pieces are added one at a time | Sine waves stack into a square wave |
| Balance | Both sides change together and stay level | Solving an equation |
| Flow | Things move around a loop or along a path | Carbon cycling through a leaf |
| Split | One thing divides or branches | Cell division |
| Zoom | The camera moves in or out to reveal another level | A hose becomes a tube up close |
| Compare | Two things run side by side | +2 vs. ×2 growth |
| Transform | One thing morphs into another as a value changes | A parabola slides as `h` and `k` change |
| Timeline | Events build up along a time axis | Anomalies piling up before a revolution |
